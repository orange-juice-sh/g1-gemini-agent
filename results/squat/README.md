# しゃがむポリシーの学習と試験の記録

棚の下の段の物（高さ約 0.5m）を、しゃがんで両手で取るためのポリシー。Isaac Lab 2.3.1 の PPO（rsl_rl）で学習し、
MuJoCo に移して使う（歩行は Unitree 公式のポリシーのまま。止まっているときだけ切り替える）。

## 学習の経過（lab/g1_squat/ の設定。各版のコミットメッセージに詳しい説明がある）

| 版 | 変えたこと | 結果 |
|---|---|---|
| v1 | 高さの指令を追う | 立ったまま（しゃがまない局所解） |
| v2 | 高さの追従の点を強める | 深いしゃがみで 94% が転倒 |
| v3 | 高さの指令をゆっくり変える | Isaac Lab では誤差 3.4cm。MuJoCo では 0.45m で転倒 |
| v4 | 関節の PD を MuJoCo と同じにし、時間刻み 0.002 秒 | 学習が遅すぎて中止 |
| v5 | しゃがむ範囲を 0.55〜0.80m に絞り、腕を前に伸ばす練習 | MuJoCo でも誤差 2cm。ただし股を 0.8 rad ひねり、体が 49〜73° 回る（Isaac Lab の中でも回っていた） |
| v6 | v5 の続きから、回転に強い罰 | 転倒 55% に悪化 |
| v7 | ひねりの罰を強めて一から | 学習が不安定になり、最後は転倒 98% |
| v8 | 股と腰のひねりを固定 | 片足を踏み出して足を開き、体が 50° 回る |
| v9 | 左右の脚を鏡のように同じ動きに | 回らないが、ほとんどしゃがまない（誤差 8.5cm） |
| v10 | 倒れる罰を弱め、追従の点を強める。案A（左右をそろえる）と案B（足を浮かせる罰を強める）を比較 | 案B: 誤差 1〜2cm、回転 9° 以内、歩行に戻せる |
| v11 | 物を両手ではさむ腕の姿勢（肘 1.4 rad）も練習 | しゃがむ精度は同じ |
| v12 | 試行の始めの状態（体の速度・回転、関節）に一様な乱数 | 本番と同じ流れで青 8/12・黄 5/12 |
| v13 | 試行の 7 割を、MuJoCo で集めた「歩行から切り替える瞬間の状態」（11,331 個）から始める | **青 12/12・黄 7/12**（既定。1800 回目のモデル） |

## 学習以外で直したこと（g1_agent/）

- 棚の見えない当たり判定の前の面を 0.15m 奥へ（しゃがむと膝が当たって後ろに押されていた）
- 肩の付け根と胴体の当たり判定を外す（両手を前の低い位置で寄せると肩が胴体に当たり、手が 7〜9cm 届かなかった）
- しゃがむ前の位置合わせ（棚に垂直な向きで物の 0.28m 手前へ、小さな速度指令で寄せる）、腰の目標は物の高さ＋0.06m
- しゃがんだあとに向きが 12° 以上ずれたら、立ち上がってやり直す（2 回まで）

## 試験

`python scripts/test_pick_demo_flow.py <ポリシー.npz> 4`: 受付・休憩スペース・充電ステーションから 4 つの向きで開始し、
休憩スペースへ行って下の段の物を取り、受付に置く（AI なし、スキルを直接呼ぶ）。

- demo_flow_v12_1597.txt: 青 8/12、黄 5/12
- demo_flow_v13_1800.txt: 青 12/12、黄 7/12
